Galaxy Surveys (BAO/RSD + SDSS) MCP Server. Start with list_galaxy_datasets; list_galaxy_skills for recipes. Three tool families: (1) BAO — fetch/fit/plot BAO distance measurements from DESI DR2/DR1, eBOSS DR16, BOSS DR12, 6dFGS, SDSS MGS; fit LCDM (Om, H0*rd) or w0waCDM with optional CMB/SN priors. (2) SDSS — query SDSS SkyServer (SQL), fetch galaxy catalogs, compute absolute magnitudes & colours, plot CMD and redshift distributions. (3) GSWLC — query the GALEX-SDSS-WISE Legacy Catalog A2 (640k galaxies), stellar masses, SFRs, dust, plot the star-forming main sequence, cross-match with SDSS. Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. Heavy tools (fit_bao_cosmology) can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
