Galaxy Surveys (BAO/RSD + SDSS + GSWLC + LSS clustering) MCP Server. Start with list_galaxy_datasets; list_galaxy_skills for recipes. Kinds of data: catalogs (object-level), summary statistics (measurements with covariance) and published results (for comparison only); build analyses on catalogs and summary statistics. Four tool families: (1) BAO [summary statistics] — fetch/fit/plot BAO distance measurements from DESI DR2/DR1, eBOSS DR16, BOSS DR12, 6dFGS, SDSS MGS; fit LCDM (Om, H0*rd) or w0waCDM with optional CMB/SN priors; compare_bao_surveys overlays a published Planck reference line (for comparison only). (2) SDSS [catalogs] — query SDSS SkyServer (SQL), fetch galaxy catalogs, compute absolute magnitudes & colours, plot CMD and redshift distributions. (3) GSWLC [catalogs] — query the GALEX-SDSS-WISE Legacy Catalog A2 (640k galaxies), stellar masses, SFRs, dust, plot the star-forming main sequence, cross-match with SDSS. (4) LSS [from clustering catalogs to correlation-function multipoles] — fetch eBOSS DR16 / BOSS DR12 / DESI DR1 galaxy clustering catalogs (data + randoms, row-limited subsets via HTTP Range); measure correlation function multipoles xi_0(s), xi_2(s) via Landy-Szalay with FKP/systematic weights (Corrfunc or scipy cKDTree); compute n(z) histograms; fetch published P(k)/xi(s) multipoles with covariances (Beutler+17, eBOSS DR16 datavecs); plot clustering multipoles. Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. Heavy tools (fit_bao_cosmology, measure_correlation_multipoles) can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
