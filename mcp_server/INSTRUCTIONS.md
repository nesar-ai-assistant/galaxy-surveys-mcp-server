Galaxy Surveys (BAO/RSD + SDSS + GSWLC + LSS clustering + Euclid DR1) MCP Server. Start with list_galaxy_datasets; list_galaxy_skills for recipes. Kinds of data: catalogs (object-level), summary statistics (measurements with covariance) and published results (for comparison only); build analyses on catalogs and summary statistics. Five tool families: (1) BAO [summary statistics] — fetch/fit/plot BAO distance measurements from DESI DR2/DR1, eBOSS DR16, BOSS DR12, 6dFGS, SDSS MGS and DES Y6 angular BAO (non-Gaussian chi2(alpha) profile; fetch_des_y6_bao_likelihood, fetch_des_y6_clustering for w(theta)/C_ell/xi_p data vectors + covariances); fit LCDM (Om, H0*rd) or w0waCDM with optional CMB/SN priors, combining datasets via fit_bao_cosmology(datasets=['desi_dr2','des_y6_nodesi']) (use the no-DESI DES variant with DESI); compare_bao_surveys overlays a published Planck reference line (for comparison only). (2) SDSS [catalogs] — query SDSS SkyServer (SQL), fetch galaxy catalogs, compute absolute magnitudes & colours, plot CMD and redshift distributions. (3) GSWLC [catalogs] — query the GALEX-SDSS-WISE Legacy Catalog A2 (640k galaxies), stellar masses, SFRs, dust, plot the star-forming main sequence, cross-match with SDSS. (4) LSS [from clustering catalogs to correlation-function multipoles] — fetch eBOSS DR16 / BOSS DR12 / DESI DR1 galaxy clustering catalogs (data + randoms, row-limited subsets via HTTP Range); measure correlation function multipoles xi_0(s), xi_2(s) via Landy-Szalay with FKP/systematic weights (Corrfunc or scipy cKDTree); compute n(z) histograms; fetch published P(k)/xi(s) multipoles with covariances (Beutler+17, eBOSS DR16 datavecs); plot clustering multipoles. (5) Euclid DR1 [catalogs] — fetch_euclid_catalog queries the ESA Euclid archive (anonymous TAP) for photometric or spectroscopic Wide-Survey galaxy samples by cone/box with quality cuts; fetch_euclid_strong_lenses serves the ECLIPSE strong-lens catalogue. DR1-Foundation has no shear/clustering 2-pt statistics or covariances (expected with DR1 Complete, mid-2027). Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. Heavy tools (fit_bao_cosmology, measure_correlation_multipoles) can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
