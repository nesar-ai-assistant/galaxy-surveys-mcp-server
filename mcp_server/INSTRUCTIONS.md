Galaxy Surveys (BAO/RSD + SDSS + GSWLC + LSS clustering) MCP Server. Start with list_galaxy_datasets; list_galaxy_skills for recipes. Data tiers: tier 1 = raw catalogs, tier 2 = summary statistics, tier 3 = published inference (comparison only). Four tool families: (1) BAO [tier 2] — fetch/fit/plot BAO distance measurements from DESI DR2/DR1, eBOSS DR16, BOSS DR12, 6dFGS, SDSS MGS; fit LCDM (Om, H0*rd) or w0waCDM with optional CMB/SN priors; compare_bao_surveys is tier 3 (Planck reference line). (2) SDSS [tier 1] — query SDSS SkyServer (SQL), fetch galaxy catalogs, compute absolute magnitudes & colours, plot CMD and redshift distributions. (3) GSWLC [tier 1] — query the GALEX-SDSS-WISE Legacy Catalog A2 (640k galaxies), stellar masses, SFRs, dust, plot the star-forming main sequence, cross-match with SDSS. (4) LSS [tier 1 + tier 2] — fetch eBOSS DR16 / BOSS DR12 / DESI DR1 galaxy clustering catalogs (data + randoms, row-limited subsets via HTTP Range); measure correlation function multipoles xi_0(s), xi_2(s) via Landy-Szalay with FKP/systematic weights (Corrfunc or scipy cKDTree); compute n(z) histograms; fetch published P(k)/xi(s) multipoles with covariances (Beutler+17, eBOSS DR16 datavecs); plot clustering multipoles. Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. Heavy tools (fit_bao_cosmology, measure_correlation_multipoles) can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
